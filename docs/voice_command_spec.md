# 音声コマンド仕様書

## 基本方針

AI APIは使用しない。

決まった音声コマンドで操作する。

Android / iPhone / Webクライアントは検索・判定ロジックを持たず、認識した文字列をサーバー共通APIへ送信する。

## 共通API

### GET /api/voice-command

パラメータ:

- `q`: SpeechRecognizerなどで認識した音声文字列

例:

```text
/api/voice-command?q=再生
/api/voice-command?q=最新
/api/voice-command?q=日曜天国を再生
/api/voice-command?q=TBSを探して
/api/voice-command?q=止めて
/api/voice-command?q=状態
```

再生レスポンス:

```json
{
  "ok": true,
  "action": "play",
  "message": "最新の録音を再生します",
  "file_id": "xxxxxxxx"
}
```

エラーレスポンス:

```json
{
  "ok": false,
  "message": "録音が見つかりません"
}
```

Day25時点では固定コマンドに加えて、番組名・キーワード検索コマンドに対応する。

| コマンド | action | 内容 |
| --- | --- | --- |
| 再生 | play | 最新録音1件のfile_idを返す |
| ○○を再生 | play | ○○で録音を検索し、最新1件のfile_idを返す |
| ○○を探して | play | ○○で録音を検索し、最新1件のfile_idを返す |
| 複数候補がある検索語 | select | 候補一覧と選択依頼メッセージを返す |
| 1番 / 一番 / いちばん | play | 保存中候補の1件目を返す |
| 2番 / 二番 / にばん | play | 保存中候補の2件目を返す |
| 3番 / 三番 / さんばん | play | 保存中候補の3件目を返す |
| 最新 | play | 保存中候補がある場合は1件目、ない場合は最新録音を返す |
| キャンセル | none | 保存中候補を破棄する |
| 止めて | pause | クライアント側の再生停止 |
| 状態 | status | クライアント側の状態確認 |

検索コマンドでは、サーバー側で末尾の操作語を除去して検索語を作る。

除去対象:

- `を再生`
- `再生`
- `を探して`
- `探して`
- `を聞きたい`
- `聞きたい`
- `を聴きたい`
- `聴きたい`

検索対象:

- `title`
- `station`
- `filename`
- `date`
- `path`

検索結果が1件以上ある場合、録音一覧の並び順に従って最新の1件を返す。

```json
{
  "ok": true,
  "action": "play",
  "message": "日曜天国を再生します",
  "file_id": "xxxxxxxx"
}
```

Day28以降、検索結果が複数件ある場合はすぐに再生せず、候補一覧を返す。
候補管理と選択処理はサーバー側 `/api/voice-command` に集約し、クライアントは `message` の読み上げと次の音声文字列送信だけを行う。

```json
{
  "ok": true,
  "action": "select",
  "message": "3件見つかりました。1番、辛坊治郎 ズーム そこまで言うか！ 7月6日。2番、辛坊治郎 ズーム そこまで言うか！ 7月5日。3番、辛坊治郎 ズーム そこまで言うか！ 7月4日。番号を選んでください。",
  "candidates": [
    {
      "index": 1,
      "file_id": "xxxxxxxx",
      "title": "辛坊治郎 ズーム そこまで言うか！",
      "station": "ニッポン放送",
      "date": "2026-07-06"
    }
  ]
}
```

読み上げる候補は最大3件、サーバーが一時保存する候補は最大5件とする。
現時点ではシングルユーザー前提のメモリ保存で、将来は `session_id` や `client_id` ごとに管理する。

候補選択レスポンス:

```json
{
  "ok": true,
  "action": "play",
  "message": "1番を再生します",
  "file_id": "xxxxxxxx"
}
```

キャンセルレスポンス:

```json
{
  "ok": true,
  "action": "none",
  "message": "キャンセルしました"
}
```

候補がない状態で番号選択された場合:

```json
{
  "ok": false,
  "message": "選択できる候補がありません"
}
```

検索結果が0件の場合:

```json
{
  "ok": false,
  "message": "日曜天国の録音が見つかりません"
}
```

Android / iPhone / Webクライアントは、`action=play` と `file_id` を受け取ったらその録音を再生する。検索語抽出・録音検索・再生対象file_idの選択はサーバー側に集約する。
